# 説明資料

読む人で2冊に分けてある。

| PDF | 読む人 | 内容 | ページ |
|:--|:--|:--|--:|
| `A_システム解説（説明する側）.pdf` | 導入を説明する人・管理する人 | 何を解決するか / 全体の流れ / 画面の構成 / 運用サイクル / 在庫の動き方 / 計算式 / アラート8区分 / 設定できること / データの入れ方 / 運用上の注意 | 9 |
| `B_操作マニュアル（操作する側）.pdf` | 毎日使う人 | 1日の流れ / HOMEの見方 / 在庫一覧 / 対応状況 / 入出庫の登録 / 出荷先と入庫元 / 商品の追加 / 選択肢の追加 / CSV取込 / 困ったとき | 7 |

A は「なぜそう判定するのか」まで書いてある。B は画面の触り方だけで、理屈には踏み込まない。

## 作り直すとき

図はすべて、その場に書いたSVG（外部ライブラリなし）。

| ファイル | 中身 |
|:--|:--|
| `content.py` | 本文。2冊ぶんの章立てと文章 |
| `_figures.py` | 図（SVG）11点 |
| `build.py` | 体裁（A4の印刷用CSS）とPDF化 |

```bash
python3 docs/build.py        # HTML だけ書き出す（ブラウザで確認できる）
python3 docs/build.py --pdf  # 続けてヘッドレスChromeでPDFにする
```

画面を変えたら、対応する節と図を直してから作り直すこと。
各ページが1枚に収まっているかは、`.page` の高さが A4本文（269mm ≒ 1017px）を超えていないかで確かめられる。
