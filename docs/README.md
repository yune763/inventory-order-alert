# 説明資料

内容ごとに分けたPDF。1冊が厚いと読まれないので、「知りたいことが載っている1冊だけ渡す」使い方を想定している。

| PDF | 内容 | 誰向け |
|:--|:--|:--|
| `01_システム概要.pdf` | 何を解決するか / 全体の流れ / 画面の構成 / 1日の使い方 | 全員・導入説明 |
| `02_判定のしくみ.pdf` | 在庫の推移と3本の線 / 計算式 / アラート8区分の順序 / 優先度 | 発注を判断する人 |
| `03_毎日の操作.pdf` | HOMEの見方 / 在庫一覧の絞り込み / 対応状況の使い分け | 毎日使う人 |
| `04_入出庫の登録.pdf` | 入庫・出庫・調整の入れ方 / 出荷先・入庫元 / 判定への効き方 | 現場・倉庫担当 |
| `05_商品とマスタの管理.pdf` | 商品の追加と品番の採番 / 仕入先・保管場所・出荷先 / 判定パラメータ | 管理担当 |
| `06_CSV取込と移行.pdf` | 旧シートからの引っ越し / 部分更新 / 入出庫CSV / 書き出し | 移行担当・情報システム |

## 作り直すとき

図はすべて、その場に書いたSVG（外部ライブラリなし）。内容は `content.py`、体裁は `build.py` にある。

```bash
python3 docs/build.py        # HTML だけ書き出す（ブラウザで確認できる）
python3 docs/build.py --pdf  # 続けてヘッドレスChromeでPDFにする
```

画面を変えたら、対応する節と図を直してから作り直すこと。
