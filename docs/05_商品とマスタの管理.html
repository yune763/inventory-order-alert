商品とマスタの管理

商品の登録（品番の採番）と、仕入先・保管場所・出荷先の管理。

欠品 / 発注漏れ / 過剰在庫 / 在庫精度（棚卸差異）を、在庫数と出荷実績から自動で判定するシステム

1. 商品を追加する

  1. 「在庫一覧」→ 右上の「商品を追加」
  2. カテゴリを選んでから「採番」を押すと、品番（商品コード）が自動で入ります。 手で入れてもかまいません。
  3. 商品名・単位・保管場所・仕入先を入れます。仕入先名を選ぶと仕入先コードも一緒に入ります。
  4. 発注リードタイム日数を必ず入れます。ここが発注点計算の中核で、空欄だと発注判定が働きません。
  5. 理論在庫数・引当数・期間出庫数などを入れて「保存する」。

2. 品番（商品コード）の採番

それぞれ専用ページがあり、一覧＋右上の「＋ 新規登録」という同じ作りです。 行ごとの「編集」を押したときだけ入力欄に変わります。

4. 判定パラメータ

全商品に共通で効く設定です。変えるとその場で全商品の判定が計算し直されます（保存済みの判定を 書き換えるのではなく、毎回この値で計算しているためです）。

項目既定 大きくすると小さくすると
消化傾向の集計期間30日 判定が安定するが、需要の変化に鈍くなる季節変動に追従するが、数字がブレやすい
安全在庫日数（既定値）7日 欠品しにくくなるが、在庫が増える在庫は減るが、欠品リスクが上がる
発注サイクル14日 発注回数は減るが、1回の量と在庫が増えるこまめな発注になり、事務負荷が上がる
滞留とみなす日数90日 滞留の警告が出にくくなる季節商品が滞留扱いされやすい
棚卸差異を見逃す範囲0 小さなズレを無視できる1個のズレも棚卸差異として出る
いじる順番。まずは既定のまま1か月運用し、「欠品が出た商品は安全在庫日数を延ばす」 「毎週同じ商品で発注推奨が出て事務が重い場合は発注サイクルを延ばす」というように、 実績を見てから1つずつ動かすのが安全です。

商品ごとに上書きできる値

安全在庫日数は商品ごとに設定でき、入っていればそちらが優先されます（空欄なら上の既定値）。 切らすと現場が止まる商品だけ長めにする、といった使い分けができます。
