在庫・発注アラート　04

入出庫の登録

入庫・出庫・調整の入れ方と、出荷先・入庫元の記録。

欠品 / 発注漏れ / 過剰在庫 / 在庫精度（棚卸差異）を、在庫数と出荷実績から自動で判定するシステム

1. 入出庫を登録すると何が変わるか

在庫数を手で書き換える代わりに、動いた分を1件ずつ積み上げます。登録するたびに理論在庫が増減します。

図7　入出庫と理論在庫の関係。取り消し（削除）や数量の修正をすると、在庫も同じだけ戻ります。
区分在庫への効き方使うとき
入庫 増える（＋）仕入先から入荷した／他倉庫から移ってきた／現場から返ってきた
出庫 減る（−）得意先・現場へ出荷した／自社で使った
調整 符号のとおり（±）棚卸で差異が出た／破損・紛失を反映する
入庫・出庫にマイナスは入れられません。 減らしたいときは区分を「調整」にして、マイナスの数量で入れます。 こうしておかないと、入庫と出庫の合計が実態と合わなくなり、後から履歴を追えなくなるためです。

2. 登録のしかた

  1. 「入出庫」を開く。（商品の明細画面からでも同じフォームが使えます）
  2. 商品を探す。品番でも商品名でも型番でも、一部を打てば候補が出ます。 候補には商品名と現在庫が並ぶので、品番が合っているかその場で確かめられます。
  3. 日付・区分・数量を入れます。日付は今日が最初から入っています。
  4. 出庫なら出荷先、入庫なら入庫元を選びます（どちらも任意）。
  5. 伝票番号・備考を入れて「登録する」。理論在庫がその場で増減します。
間違えたとき。履歴の行の右にある「取消」を押すと、確認のうえ取り消せます。 在庫も同じだけ戻ります。数量だけ直したいときは、取り消してから入れ直してください。

3. 出荷先と入庫元

項目つく区分選び方
出荷先出庫のみ 「出荷先」画面に登録したものから選ぶ。得意先・現場・自社拠点を住所や担当者つきで管理できる
入庫元入庫のみ 仕入先マスタと、これまでに入力した入庫元が候補に出る。候補に無い相手も自由に書ける

出荷先だけ専用の管理画面があるのは、住所・担当者・電話まで記録して「どこへ何を出したか」を 集計したいためです。入庫元はほとんどが仕入先なので、二重管理にならないよう文字列で持っています。

出荷先別の実績

「入出庫」画面と「出荷先」画面に、直近30日でどこへいくつ出たかが数量・件数・金額（販売単価ベース）で 出ます。「明細」を押すと、その出荷先の出庫だけに絞った履歴が開きます。

4. 入出庫を入れると判定も変わる

出庫を1件でも登録した商品は、期間出庫数（直近30日に出た数）を台帳から自動で集計するようになります。 手で入れる必要がなくなり、実績どおりの発注点が出ます。

図8　期間出庫数の出どころ。商品ごとに切り替わります。 一覧では、台帳から集計した値に「台帳」と印が付きます。
項目入出庫を登録している商品登録していない商品
理論在庫数入出庫のたびに自動で増減手入力・CSVの値
期間出庫数直近30日の出庫の合計手入力・CSVの値
最終入庫日 / 最終出庫日台帳の最新日手入力・CSVの値
全商品を一度に切り替える必要はありません。 よく動く商品から入出庫を入れ始めれば、その商品だけ精度が上がります。 残りは今までどおりCSVの数字で判定され続けます。

5. まとめて入れる

販売管理や受発注システムから出した明細があるなら、「取込・書き出し」の入出庫CSVから まとめて取り込めます。詳しくは「06 CSV取込と移行」を参照してください。
