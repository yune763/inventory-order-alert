2. HOMEを開く

図1　上の件数 → 区分の内訳 → 要対応リスト、の順に見ます。
  1. A（即日対応）の件数を見る。0件なら、今日中に手を打つべき商品はありません。
  2. 要対応リストを上から片付ける。「推奨アクション」に 「本日中に 230 発注（リードタイム7日）」のように数量と期限が書かれています。
  3. 発注したら対応状況を「発注済み」に変える。一覧のプルダウンからその場で変えられます。

3. 在庫一覧を使う

旧スプレッドシートと同じ42項目が、同じ並びで入っています。

左3列は固定されている

横にスクロールしても対応状況・商品コード・商品名は画面に残ります。

見たい区分だけ表示する

表の上の「表示する区分」を押すと、その区分の列がまとめて隠れます。 選んだ状態はブラウザが覚えているので、次に開いたときも同じ見え方になります。

絞り込みと並べ替え

  • キーワード（商品コード・商品名・型番・仕入先）、アラート区分、優先度、対応状況、カテゴリ、保管場所、仕入先で絞れます
  • 絞り込んだ状態はURLに残るので、そのままブックマークや共有ができます
  • 見出しをクリックすると並べ替わります
  • 「CSVで書き出す」は、いま絞り込んでいるものだけを出します（仕入先ごとの発注リストに便利）
「自動」と付いた列は直せません。 有効在庫・発注点・アラート区分などは、開くたびに計算し直しているためです。 変えたいときは、もとになる数字（理論在庫・引当・リードタイムなど）を直します。

4. 対応状況を付ける

図2　対応状況の流れ。人が選ぶ列で、計算で書き換わることはありません。
対応状況使うとき
即日対応今日中に発注・手配すると決めた行に付けて、作業待ちを見えるようにする
要確認数字が怪しい・現物を見てから決める行
発注済み発注を出した行。HOMEの「手当て済み」件数に入る
保留今は動かさないと決めた行
廃盤もう仕入れない商品。在庫を売り切る対象
発注NG仕入先都合などで発注できない行
アラートが消えるのはいつか。 対応状況を変えてもアラート区分は消えません（機械の判定と人の対応は別物なので）。 発注残（入荷予定の数）を入力するか、入庫を登録した時点で判定そのものが変わります。

5. 入出庫を登録する

図3　登録するたびに理論在庫が動きます。取り消せば同じだけ戻ります。
区分在庫への効き方使うとき
入庫 増える（＋）仕入先から入荷した／他倉庫から移ってきた／現場から返ってきた
出庫 減る（−）得意先・現場へ出荷した／自社で使った
調整 符号のとおり（±）棚卸で差異が出た／破損・紛失を反映する
  1. 「入出庫」を開く。（商品の明細画面からでも同じフォームが使えます）
  2. 商品を探す。品番でも商品名でも型番でも、一部を打てば候補が出ます。 候補には商品名と現在庫が並ぶので、品番が合っているかその場で確かめられます。
  3. 日付・区分・数量を入れます。日付は今日が最初から入っています。
  4. 出庫なら出荷先、入庫なら入庫元を選びます（どちらも任意）。
  5. 伝票番号・備考を入れて「登録する」。理論在庫がその場で増減します。
入庫・出庫にマイナスは入れられません。 減らしたいときは区分を「調整」にして、マイナスの数量で入れます。 入庫と出庫の合計が実態と合わなくなり、後から履歴を追えなくなるためです。

6. 出荷先と入庫元

項目つく区分選び方
出荷先出庫のみ 「出荷先」画面に登録したものから選ぶ
入庫元入庫のみ 仕入先と、これまでに入力した入庫元が候補に出る。候補に無い相手も自由に書ける

「入出庫」画面と「出荷先」画面に、直近30日でどこへいくつ出たかが数量・件数・金額で出ます。 「明細」を押すと、その出荷先の出庫だけに絞った履歴が開きます。

7. 商品を追加する

  1. 「在庫一覧」→ 右上の「商品を追加」
  2. カテゴリを選んでから「採番」を押すと、品番が自動で入ります（手入力も可）
  3. 商品名・単位・保管場所・仕入先を入れる。仕入先名を選ぶと仕入先コードも一緒に入ります
  4. 発注リードタイム日数を必ず入れる。ここが空欄だと発注判定が働きません
  5. 理論在庫数・引当数・期間出庫数などを入れて「保存する」
商品コードは後から変えないでください。 CSV取込の照合キーであり、入出庫の履歴もこのコードで結び付いています。

8. 選択肢を足す

仕入先・保管場所・出荷先は、それぞれ専用ページの右上「＋ 新規登録」から足します。 行ごとの「編集」を押したときだけ入力欄に変わります。

  • 対応状況・カテゴリ・単位は「マスタ」画面にあります
  • 使われているものは削除できません。一覧の使用件数が0のものだけ消せます。 使わなくなったものは「非表示」に切り替えてください（一覧には残りますが、選択肢に出なくなります）

9. CSVで取り込む

  1. 「取込・書き出し」を開く
  2. 商品なら商品CSV、入出庫なら入出庫CSVにファイルを指定（シートからの貼り付けも可）
  3. 「内容を確認する」で件数とエラーを見る
  4. 問題なければ「◯件を取り込む」
種類必須の見出しエラーがあったら
商品CSV商品コード / 商品名その行だけ飛ばして取り込む
入出庫CSV日付 / 区分 / 商品コード / 数量1件も取り込まない（在庫が合わなくなるため）

10. 困ったとき

発注したのにアラートが消えない

対応状況を「発注済み」にしても、アラート区分は消えません（機械の判定と人の対応は別だからです）。 商品編集で発注残数（入荷予定）を入れるか、入庫を登録すると判定そのものが変わります。

在庫数を直したい

実地棚卸の結果なら実棚在庫数に入れてください（入っていればそちらが現物として扱われます）。 入出庫を使っている商品なら、区分「調整」で差分を入れるほうが履歴に残って追いやすくなります。

入出庫を間違えて登録した

履歴の行の右にある「取消」を押してください。在庫も同じだけ戻ります。

「発注推奨数」が思ったより多い／少ない

発注推奨数は「適正在庫上限まで戻す量」を、最小発注数(MOQ)と発注ロット単位に切り上げた数です。 多すぎるならロット単位かMOQを、少なすぎるなら安全在庫日数やリードタイムを確認してください。

期間出庫数が自分で入れた値と違う

その商品で出庫を登録していると、直近30日の出庫の合計が自動で使われます（一覧に「台帳」と印が付きます）。 手入力の値に戻したい場合は、その商品の出庫の登録を取り消してください。

画面が出てくるまで遅い

夜間・休日の最初の1回は、システムが休止状態から起きるため30秒ほどかかります。 平日の9〜21時は起こしてあるので、待たされることはありません。

ID・パスワードを聞かれる

URLを開いた時点で出る入口の鍵です。管理者に確認してください。
