在庫・発注アラート　03

毎日の操作

HOMEの見方と、在庫一覧での絞り込み・対応状況の付け方。

欠品 / 発注漏れ / 過剰在庫 / 在庫精度（棚卸差異）を、在庫数と出荷実績から自動で判定するシステム

1. 朝いちばん：HOMEを開く

図5　HOMEの見方。上の件数 → 区分の内訳 → 要対応リスト、の順に見ます。
  1. A（即日対応）の件数を見る。0件なら、今日中に手を打つべき商品はありません。
  2. 要対応リストを上から片付ける。「推奨アクション」に 「本日中に 230 発注（リードタイム7日）」のように、数量と期限が書かれています。
  3. 発注したら、その行の対応状況を「発注済み」に変える。 一覧の対応状況はその場で変えられます。次の朝から、その行は手当て済みとして扱われます。
アラートが消えるのはいつか。 対応状況を変えてもアラート区分は消えません（機械の判定と人の対応は別物なので）。 実際に発注残（入荷予定の数）を入力するか、入出庫で入庫を登録した時点で、判定そのものが変わります。

2. 在庫一覧の使い方

旧スプレッドシートと同じ42項目が、同じ並びで入っています。

左3列は固定されている

横にスクロールしても対応状況・商品コード・商品名は画面に残ります。 どの行を見ているか見失わないためです。

見たい区分だけ表示する

表の上に「表示する区分」のボタンが並んでいます。押すと、その区分の列がまとめて隠れます。 選んだ状態はブラウザが覚えているので、次に開いたときも同じ見え方になります。

区分入っている項目
基本情報カテゴリ / 規格・型番 / 単位 / 保管場所
仕入先・発注条件仕入先 / 単価 / リードタイム / MOQ / ロット
在庫状況理論在庫 / 実棚在庫 / 棚卸差異 / 引当 / 発注残 / 有効在庫 / 入荷予定日 / 在庫金額
消化傾向期間出庫数 / 平均日次出庫 / 在庫日数 / 欠品予測日
発注判定安全在庫 / 発注点 / 適正在庫上限 / 発注推奨数 / 発注期限日
アラートアラート区分 / 優先度 / 理由 / 推奨アクション
履歴・管理最終入庫日 / 最終出庫日 / 最終棚卸日 / 滞留日数 / 備考 / 更新日時

絞り込みと並べ替え

  • キーワード（商品コード・商品名・型番・仕入先）、アラート区分、優先度、対応状況、カテゴリ、保管場所、仕入先で絞れます
  • 絞り込んだ状態はURLに残るので、そのままブックマークや共有ができます
  • 見出しをクリックすると並べ替わります（優先度・商品コード・有効在庫・在庫日数・発注期限・在庫金額・更新日時）
  • 「CSVで書き出す」は、いま絞り込んでいるものだけを出します
「自動」と付いた列は直せません。 有効在庫・発注点・アラート区分などは、開くたびに計算し直しているためです。 これらを変えたいときは、もとになる数字（理論在庫・引当・リードタイムなど）を直します。

3. 対応状況の使い分け

図6　対応状況の流れ。人が選ぶ列で、計算で書き換わることはありません。
対応状況使うとき
即日対応今日中に発注・手配すると決めた行に付けて、作業待ちを見えるようにする
要確認数字が怪しい・現物を見てから決める行
発注済み発注を出した行。HOMEの「手当て済み」件数に入る
保留今は動かさないと決めた行
廃盤もう仕入れない商品。在庫を売り切る対象
発注NG仕入先都合などで発注できない行
選択肢は増やせます。「マスタ」画面の対応状況に行を足すと、その場でプルダウンに出ます。 色も指定できるので、一覧での見分けがつきやすくなります。
