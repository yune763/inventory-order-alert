# 旧スプレッドシート版（参考用）

サイト版に移行する前の、Googleスプレッドシート＋GAS で運用していたときの一式。
**現在の運用はサイト側（`../webapp`）。ここのファイルは動かす必要が無い。**

| ファイル | 内容 |
|:--|:--|
| `在庫アラート.gs` / `.gs.bak` | 再計算・メール通知・日次トリガーの Apps Script |
| `在庫・発注アラート_構築プロンプト.md` | スプレッドシート版を再現するためのAI向けプロンプト |
| `headers.txt` / `header_row.csv` / `header_row.tsv` | 1行目（42項目）の見出し |
| `在庫・発注アラート_使い方.html` / `.pdf` | スプレッドシート版の使い方ガイド |

計算ロジックとアラート区分はサイト版にそのまま引き継いでいる（`../在庫・発注アラート_設計書.md`）。
違うのは「どこで計算するか」だけ:

- 旧: GAS の `recalcAll` が自動列をシートに書き込む＋AG列は ARRAYFORMULA
- 新: `inventory_items_evaluated` ビューが読むたびに計算する（保存しない）
